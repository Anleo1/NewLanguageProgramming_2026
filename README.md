# NewLanguageProgramming_2026

## Темы для индивидуального задания:
### 1. Многопоточность
#### 1.1. Параллельное суммирование массива. Программа читает файл numbers.txt с массивом чисел, делит его на части по числу потоков, каждый поток считает сумму своей части, затем результаты складываются. Итоговая сумма записывается в result.txt. Использовать только стандартные потоки, mutex или atomic.
#### 1.2. Многопоточный поиск максимума и минимума. Программа читает файл data.txt с числами. Массив делится между потоками, каждый поток находит максимум и минимум в своей части, затем главный поток выбирает общий максимум и минимум. Результат записывается в minmax.txt.
#### 1.3. Многопоточный подсчёт простых чисел в диапазоне. Пользователь задаёт начало и конец диапазона в файле range.txt и число потоков. Диапазон делится на части, каждый поток проверяет числа на простоту в своей части. Главный поток суммирует количество найденных простых чисел. Результат записывается в primes.txt.
#### 1.4. Многопоточное умножение матриц. Программа читает две матрицы из файлов matrix_a.txt и matrix_b.txt, проверяет совместимость размеров и умножает их. Матрица-результат делится по строкам между потоками. Результат записывается в matrix_c.txt.

### 2. Алгоритмическая задача
#### 2.1. Факториал числа. Пользователь вводит неотрицательное целое число в файл input.txt. Нужно вычислить факториал рекурсивно и записать результат в output.txt. Предусмотреть проверку на отрицательное число.
#### 2.2. Числа Фибоначчи. Пользователь вводит номер числа в файл input.txt. Нужно вычислить число Фибоначчи рекурсивно и записать результат в output.txt. Ограничить ввод небольшим значением.
#### 2.3. Рекурсивный алгоритм Евклида для нахождения НОД. Пользователь вводит два целых положительных числа в файл input.txt. Программа рекурсивно вычисляет наибольший общий делитель и записывает результат в output.txt. Предусмотреть проверку на ноль и отрицательные числа.
#### 2.4. Бинарный поиск в отсортированном массиве. Массив чисел задаётся в файле array.txt, искомое значение — в файле target.txt. Реализовать бинарный поиск. Индекс найденного элемента или сообщение об отсутствии записывается в result.txt.

### 3. Ввод/вывод в консоль/файл
#### 3.1. Подсчёт строк, слов и символов в файле. Программа читает текстовый файл text.txt и выводит количество строк, слов и символов. Слова разделяются пробелами и переводами строк. Результат выводится в консоль и записывается в файл stats.txt.
#### 3.2. Статистика чисел из файла. Программа читает текстовый файл numbers.txt с числами, пропускает пустые строки, считает минимум, максимум, сумму, среднее и количество чисел. Результат сохраняется в файл report.txt.
#### 3.3. Копирование файла. Программа копирует содержимое файла source.txt в файл copy.txt. Предусмотреть проверку существования исходного файла и обработку ошибок записи.
#### 3.4. Поиск и замена подстроки в файле. Программа читает файл source.txt, заменяет все вхождения заданной подстроки на новую строку и сохраняет результат в файл replaced.txt. Количество замен записывается в replace.log.

### 4. Клиент-серверное взаимодействие
#### 4.1. TCP echo-сервер и клиент. Сервер слушает заданный порт и возвращает клиенту полученное сообщение. Клиент подключается к серверу, отправляет строки из консоли и получает эхо-ответ. Завершение по специальной команде. Действия сервера записываются в echo.log.
#### 4.2. UDP echo-сервер и клиент. Сервер принимает UDP и отправляет их обратно. Клиент отправляет сообщения и выводит ответ. Лог работы записывается в udp.log.
#### 4.3. Сервер текущего времени. Клиент подключается к серверу и отправляет запрос. Сервер возвращает текущую дату и время. Клиент выводит полученный ответ. История запросов записывается в time.log.
#### 4.4. Сервер-калькулятор на два числа. Клиент отправляет серверу два числа и знак операции: сложение, вычитание, умножение или деление. Сервер выполняет операцию и возвращает результат. Все операции записываются в calc.log.

### 5. Конвертация данных из одного формата в другой
#### 5.1. CSV в TSV и обратно. Программа читает файл data.csv, где поля разделены запятыми и не содержат запятых внутри, и сохраняет его в data.tsv. Обратная конвертация сохраняет data.tsv в data.csv.
#### 5.2. Цвет HEX в RGB и обратно. Программа читает файл color_hex.txt, где каждая строка содержит цвет в формате #RRGGBB, и переводит его в запись rgb(R, G, B). Результат записывается в color_rgb.txt. Обратная конвертация читает color_rgb.txt и записывает color_hex.txt.
#### 5.3. JSON в YAML. Программа читает файл data.json с массивом объектов и сохраняет его в data.yaml.
#### 5.4.Markdown-таблица в CSV и обратно. Программа читает файл table.md, содержащий таблицу в формате Markdown, и сохраняет её в table.csv
